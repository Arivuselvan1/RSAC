# DSAC Website Redesign

A modern, professional redesign of the Dhanalakshmi Srinivasan Agriculture College website.

## Project Overview

This redesign focuses on:
- **Modern Design**: Clean, professional aesthetic with focus on readability
- **Enhanced UX**: Intuitive navigation, sticky header, smooth animations
- **Responsive**: Mobile-first design that works on all devices
- **Brand Colors**: Green and gold theme maintaining institutional identity
- **Content Preservation**: All original content and media retained

## Features

### Design
- Full-width hero sections with compelling imagery
- Card-based layouts for better content organization
- Ample whitespace for improved readability
- Modern color palette (Green #2d5016, Gold #d4af37)
- Clean sans-serif typography (Inter & Poppins)

### User Experience
- Sticky navigation for easy access
- Mobile-responsive hamburger menu
- Smooth scroll animations
- Interactive lightbox gallery
- Accordion for rules & regulations
- Animated statistics counter
- Scroll-to-top button

### Pages Included
1. **Home** (`index.html`) - Hero, Welcome, Features, Stats, Gallery Preview
2. **About DSAC** (`about.html`) - Trust, Chancellor, Principal, Vision/Mission
3. **Programs & Curricula** (`programs.html`) - B.Sc. Agriculture, Rules & Regulations
4. **Contact** (`contact.html`) - Contact information, form, map
5. **Admissions** (`admissions.html`) - Admission details and process

### Additional Pages (Templates)
- Departments
- Campus & Facilities
- News & Events
- Alumni
- Gallery

## Technology Stack

- **HTML5**: Semantic markup
- **CSS3**: Modern CSS with CSS Variables
- **JavaScript**: Vanilla JS for interactivity
- **Google Fonts**: Inter & Poppins
- **Font Awesome**: Icon library

## Key Improvements from Original Site

1. **Visual Hierarchy**: Clear content organization with proper headings and sections
2. **Navigation**: Streamlined menu structure with sticky header
3. **Content Display**: 
   - Dense text transformed into cards and lists
   - Accordion for lengthy regulations
   - Full-width imagery for impact
4. **Gallery**: Modern lightbox with keyboard navigation
5. **Animations**: Subtle fade-in effects and statistics counter
6. **Mobile First**: Fully responsive on all devices
7. **SEO**: Proper meta tags, semantic HTML, and heading structure
